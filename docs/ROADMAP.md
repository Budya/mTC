# mTC — план и статус

Последнее обновление: 2026-09-28. Этапы 1 и 2 полностью проверены пользователем.

## Этап 0 — каркас ✅
- Xcode-проект (Swift + AppKit, synchronized groups, arm64, macOS 14+, ad-hoc подпись, без sandbox).
- Portable-настройки в `mTC-data/` рядом с `.app` (`DataLocation`, `JSONStore`, `InstanceLock`); translocation, read-only и lock → предупреждение и работа без сохранения.
- Иконка в строке меню, режим «без Dock», глобальная клавиша `⌃⌥T`, автозагрузка через `SMAppService`.
- Две панели: колонки, сортировка, иконки, `..`, Tab/Enter/Backspace, скрытые файлы, запоминание окна и путей.
- `scripts/dist.sh` → `build/mTC-<версия>.zip`; иконка-дискета (`scripts/make-icon.swift`, `FloppyIcon`).

## Этап 1 — навигация и выделение (в работе)
Делаем по одному шагу, после каждого пользователь проверяет руками.

- [x] **1.1 Выделение файлов.** Курсор (выделенная строка таблицы) отдельно от отметок (`marked` по имени). Space/Insert, ⌘-клик, ⇧↑/⇧↓ инвертируют файл под курсором и двигают курсор (как в TC), ⇧-клик выделяет диапазон от якоря (прежние отметки сохраняются), `+`/`-` по маске (`FileMask`, диалог с «Включая папки», последняя маска в `state.json`), `*` инвертирует файлы, ⌘A переключает «всё/ничего», ⌘⇧A снимает всё. Обычный клик снимает отметки и ставит курсор (`onPlainClick`); потянули за отмеченный — тащатся все отмеченные, отметки остаются. Размер папки по Space считается в фоне. Итог выделения в строке состояния. Меню «Выделение».
- [x] **1.2 Автообновление панелей.** `DirectoryWatcher` (FSEvents, только сама папка, WatchRoot, latency 0.3 с); `reload()` сохраняет курсор (или его позицию), отметки; удалённая папка → ближайшая существующая с курсором на ветке. Сетевые изменения с других машин не видны — `⌘R`. Пользователь проверил — работает.
- [x] **1.3 Выбор диска/тома.** `DriveBar` над панелью (NSPopUpButton: тома из `Volumes.mounted()`, «Домашняя папка», «Корень /»; внутри ~ показывается «Домашняя папка», в / — «Корень /»), «свободно X из Y» (`volumeAvailableCapacityForImportantUsage`). Выбор другого тома → последняя папка панели на нём (`lastDirectoryByVolume`), текущего → его корень. NSWorkspace mount/unmount/rename → обновление списка; отключили диск текущей папки → домой (и через `reload()`, если наблюдатель сработал раньше). Проверено на подключённом образе диска. Горячей клавиши вызова списка пока нет — вместе с hotkeys.
- [x] **1.4 Вкладки.** `PanelSideViewController` на сторону: одна панель + вкладки как снимки `PanelTab` (папка, курсор, отметки, сортировка), `TabBarView` (скрыт при одной вкладке; клик, крестик/средняя кнопка, контекстное меню, двойной клик → новая). ⌘T, ⌘W (последняя → окно), ⌃Tab/⌃⇧Tab, ⌘⇧]/⌘⇧[ (keyEquivalent «}»/«{»), ⌘⇧W окно. `state.json`: `leftTabs`/`rightTabs` (`SavedPanel`), старые `leftPath`/`rightPath` — только миграция.
- [ ] **Опционально (следующий шаг, если нужно):** история назад/вперёд (⌘[ / ⌘]), ввод пути вручную, ⌘⇧H домой.


## Этап 2 — файловые операции ✅
- [x] **2.1 Панель F-клавиш + F7 новая папка.** `FunctionKeyBar` внизу окна (нереализованные кнопки неактивны). F7 / ⌘⇧N / кнопка → `TextPrompt` → `FileOperations.createDirectory` (вложенные `a/b/c`, абсолютные `/…`, `~/…`; пустое, `.`/`..` — ошибка; занятое имя → номер, как Finder: «Новая папка 2», через `uniqueURL`; в диалоге сразу свободное имя), курсор на созданную папку.
- [x] **2.2 F8 удаление.** Цели — `operationTargets()` (выделенные или файл под курсором, без «..»). F8 / Del / ⌘⌫ (меню) → Корзина (подтверждение с «Больше не спрашивать» → `settings.confirmMoveToTrash`), ⇧F8 / ⇧Del / ⌥⌘⌫ → насовсем (всегда подтверждение, destructive-кнопка). Выполняется в фоне (`FileOperations.moveToTrash/deletePermanently`); нет Корзины (`featureUnsupported`) → предложение удалить насовсем; ошибки списком. `MainWindowController` теперь получает `JSONStore<AppSettings>`. Контекстное меню по ПКМ (`PanelTableView.menu(for:)` → `contextMenu(forRow:)`, пункты через `ActionMenuItem`): по выделенному — все выделенные, по невыделенному — только он (курсор туда), по «..»/пустому — только «Новая папка…».
- [x] **2.3 F5 копирование.** `CopyOperation` (фон, `copyfile` с COPYFILE_ALL|CLONE|NOFOLLOW_SRC и колбэком прогресса; скан объёма; папки сливаются; конфликт файла → Заменить (временный файл + `rename`)/Пропустить/Оставить оба (`uniqueURL(isDirectory:)`: «a 2.txt»)/Остановить, «Применить ко всем»; копия в ту же папку → дубликат с номером; папка внутрь себя → ошибка; отмена удаляет недокопированный файл). Диалог пути (`FileOperations.copyDestination`: внутрь папки / под новым именем / создать папку для нескольких). `OperationProgressWindowController` (немодальное окно, появляется через 0,4 с, скорость, Esc = отмена); конфликт — лист на окне прогресса. После — обновление панелей, снятие выделения со скопированного, ошибки списком. F5 / ⌘⇧C / кнопка / ПКМ «Копировать в другую панель…». Проверено тестами движка (копия на другой том, отмена) и пользователем.
- [x] **2.4 F6 перемещение / ⇧F6 переименование.** `CopyOperation(mode: .move)`: тот же том (`volumeIdentifier`) → `rename(2)` с конфликтами, слияние папок (после — `rmdir` пустого источника), EXDEV → копия+удаление; другой том → `copyItem` и удаление источника только при полном успехе; «уже на месте» → ничего. UI общий с копированием (`requestTransfer`). Переименование в списке: `beginRename()` делает поле ячейки редактируемым, выделено имя без расширения (у папок целиком), Enter/клик мимо — сохранить, Esc — отмена; обновления на время правки откладываются; `FileOperations.rename` (смена регистра разрешена по `fileResourceIdentifier`, занятое имя/`/` — ошибка). F6 / ⌘⇧M / кнопка / ПКМ; ⇧F6 / F2 / ⌘⇧R (меню) / ПКМ «Переименовать». ⌘R остаётся «Обновить».
- [x] **2.5 Перетаскивание.** Источник: `pasteboardWriterForRow` (NSURL, кроме «..»); за выделенный файл при нескольких выделенных — своё перетаскивание всех (`PanelTableView.dragMarkedFiles`, стопкой). Маски: внутри mTC [.copy, .move, .generic], наружу только .copy. Приёмник: `.fileURL`; на папку/«..» — в неё, иначе в текущую (подсветка всей таблицы); запрет: в ту же папку, папку в себя (сравнение по `resolvingSymlinksInPath`); ⌘ → перемещение. Бросок → `requestsDropOf` → `startTransfer` без диалога (прогресс, конфликты). Проверено пользователем.

F5 копировать, F6 переместить/переименовать, F7 создать папку, F8 удалить (в Корзину, с ⇧ насовсем). Фоновая очередь, прогресс, диалог конфликтов. Альтернативы F-клавишам для клавиатур Mac.

## Этап 3 — удобство (в работе)
Порядок согласован: 3.1 F3 → 3.2 F4 → 3.3 навигация → 3.5 горячие клавиши → 3.6 командная строка (3.4 избранные папки отменены).

- [x] **3.1 F3 просмотр (Quick Look).** `QLPreviewPanel` с контроллером в `FilePanelViewController` (responder chain), `orderFront` — главное окно остаётся активным; следует за курсором (`tableViewSelectionDidChange`); курсор на выделенном при нескольких выделенных — показываются все выделенные; клавиши из окна просмотра пересылаются в таблицу; анимация из иконки. F3 / ⌘Y (меню) / кнопка / ПКМ, Esc закрывает. Проверено пользователем.
- [x] **3.2 F4 редактирование / ⇧F4 новый файл.** `settings.editor` → `FileOperations.editorApplication` (пусто — `urlForApplication(toOpen: .plainText)`; путь, bundle id или имя .app в /Applications и т.п.); `NSWorkspace.open(_:withApplicationAt:)`; папки — только при явно заданном редакторе. ⇧F4: `TextPrompt` (подсказка «Новый файл 2.txt»), `FileOperations.createFile` (подпапки, существующий файл — просто открыть), курсор на файл (`select(named:)`), открыть в редакторе. F4 / ⌘E / кнопка / ПКМ; ⇧F4 / ⌥⌘N / ПКМ «Новый файл…». Проверено пользователем.
- [x] **3.2а Открыть с помощью.** `openWithItems(for:)`: `urlsForApplications(toOpen:)` с пересечением для нескольких файлов, без дублей по bundle id, по умолчанию первой, иконки; «Другая программа…» — `NSOpenPanel` (.application). Подменю в ПКМ и в «Файл» (строится при открытии через `OpenWithMenuDelegate`). Приложение объявлено русским (`developmentRegion = ru`) — русские имена программ и системные окна. Проверено пользователем.
- [x] **3.3 Навигация.** История `backStack`/`forwardStack` (`HistoryEntry`: папка + курсор, лимит 100) в панели, сохраняется во вкладке (`PanelTab.back/forward`); пишется при смене папки (`navigate(recordHistory:)`), не пишется при обновлении/восстановлении вкладки/уходе из удалённой папки; пропавшие папки пропускаются; возврат в родительскую ставит курсор на папку, откуда пришли. Кнопки ‹ › в строке пути. Ввод пути: `pathField` поверх `pathLabel` (⌘L / клик), Enter — папка или файл (курсор на него), Esc, Tab — `completePath` (одна папка → имя + «/», несколько → общее начало, иначе сигнал). ⌘⇧H, ⌘⇧↑ (корень тома), ⌘\ (папка другой панели), ⌘↵ / средний клик / ПКМ — папка в новой вкладке. Меню «Переход». Проверено пользователем.
- [—] **3.4 Избранные папки** — отменено: пользователю не нужны.
- [x] **3.5а Кнопка скрытых файлов.** Переключатель с глазом (eye / eye.slash) справа на панели F-кнопок (`FunctionKeyBar(accessories:)`), синхронно с меню «Вид» и ⌘⇧.; переключение — в `MainWindowController.toggleHiddenFiles` (+ `validateMenuItem`). ⌘⇧. переназначен на keyEquivalent «>» (без Shift в маске). Проверено пользователем, ⌘⇧. теперь работает.
- [x] **3.5 Горячие клавиши.** `KeyCombo` (строки `cmd+shift+c`/`f5`/`plus`, показ `⇧⌘C`, клавиша меню с учётом Shift-знаков, Carbon-коды), `CommandCatalog` (все команды: название, раздел, значения по умолчанию; зарезервированные ⌘Q/⌘H/⌘C/⌘V/⌘X/⌘M/⇧⌘W), `Hotkeys` (`mTC-data/hotkeys.json` через `JSONStore`, ошибки файла → предупреждение при запуске, `didChange`). Панель ищет команду через `Hotkeys.shared`; меню пересобирается (сочетание с ⌘ — клавиша пункта, остальные — подсказка в названии); кнопки F-клавиш и подсказки контекстного меню берут подписи из привязок; глобальная `showHideWindow` — тоже в hotkeys.json (из settings.json убрана). Окно `HotkeysWindowController` (⌘, / меню строки меню): поиск, разделы, удаление кликом, запись нажатия (Esc — отмена; проверки: зарезервированные, буквы без модификаторов, глобальная — только с ⌘/⌃/⌥; конфликт → «Переназначить?»), «По умолчанию», «Сбросить все». Проверено пользователем.
- [x] **3.7 Цвет по типу файла.** `settings.fileColors` (`FileColorRule`: название, маски, цвет — системное имя или `#RRGGBB`), `FileColors.shared` (первое совпавшее правило, только файлы и пакеты), `PanelCellView.tint`; отметка и курсор важнее, скрытые — бледнее. Группы по умолчанию: архивы, программы, изображения, медиа, документы, код. Проверено пользователем.
- [x] **3.8 Тема оформления.** `settings.theme` (`AppTheme`: system / light / dark) → `NSApp.appearance`; меню «Вид → Тема». Цвета файлов в светлой теме затемнены на 25% (`FileColors.readable`), медиа — синий (розовый путался с отметкой), программы — коричневый. Проверено пользователем.
- [—] **3.6 Командная строка** — отложено: пользователю пока не нужна.


## Этап 4 — архивы ✅
Через системную libarchive: `mTC/Support/libarchive.h` (свои объявления — в SDK есть `libarchive.tbd`, но нет заголовков) + bridging header, `-larchive`. Никаких сторонних зависимостей.

- [x] **4.1 Распаковка в текущую папку.** `ArchiveExtractOperation`: во временную `.mtc-extract-UUID` рядом с архивом, затем один объект → на место (конфликт — `askConflict`), несколько → папка с именем архива (`ArchiveFormats.stem`, `uniqueURL`). Безопасность: пропуск `..`, ведущий `/` отрезается, запись через ссылку наружу запрещена. Пароль — `archive_read_set_passphrase_callback` → лист с `NSSecureTextField`, повтор при неверном; пароль запоминается на операцию. Одиночные .gz и т.п. — формат raw. Прогресс по прочитанным байтам архива, отмена удаляет временную папку. ⌥F9 / ⌥⌘X / меню «Файл» / ПКМ «Распаковать сюда». Проверено тестами (zip, multi, конфликты, tar.gz, 7z, .gz, пароль, вредоносные zip/tar, битый, отмена). Проверено пользователем.
- [x] **4.2 Упаковка.** `ArchiveCreateOperation` (libarchive write: zip / 7zip / pax+gzip / pax+xz; zip с паролем — `ZipEncryption`: ZipCrypto по умолчанию (открывает Finder) или AES-256; обход без захода по ссылкам, ссылки как ссылки, без `.DS_Store`, пути в NFC; временный `.mtc-pack-UUID` → rename; прогресс, отмена). Диалог `ArchiveDialog` (имя, формат с автосменой расширения, пароль и шифрование только для ZIP, «в папку другой панели»; выбор запоминается в `state.json`). Существующий архив → «Оставить оба» («Проект 2.tar.gz») / «Заменить». ⌥F5 / ⌥⌘A / меню / ПКМ «Упаковать…». Проверено тестами в обе стороны (4 формата, кириллица, ссылка, пароль, отмена). Проверено пользователем.
- [x] **4.2а Вопрос при открытии архива.** Enter / двойной щелчок / ПКМ «Открыть» по архиву (`ArchiveFormats.asksOnOpen`, кроме .pkg и .iso) → диалог «Распаковать сюда» / «Открыть программой» / «Отмена» (`requestsOpenOfArchive`). Проверено пользователем.
- [—] **4.3 Архив как папка** — отменено: пользователю не нужно, хватает распаковки и упаковки.

## Этап 5 — мощные функции ← **следующий этап, порядок не выбран**

- Определение запуска как login item (`isLaunchedAsLoginItem` через Apple Event).
