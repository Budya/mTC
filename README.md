# mTC

Двухпанельный файловый менеджер для macOS в духе Total Commander.
Не требует установки: папку `mTC` можно положить куда угодно (домашняя папка, внешний диск, `~/Tools`) и запускать оттуда.

Требования: macOS 14 Sonoma или новее, Mac на Apple Silicon (M1 и новее).

## Запуск

1. Распакуйте `mTC-<версия>.zip` в любую папку. Помещать в `/Applications` не нужно.
2. Если архив пришёл через браузер, Slack, Teams, почту или AirDrop, macOS пометит его карантином и не даст запустить приложение. Снимите пометку один раз:
   ```bash
   xattr -dr com.apple.quarantine /путь/к/mTC/mTC.app
   ```
   Если вы копировали папку с сетевой шары, флешки или из git, этот шаг обычно не нужен.
3. Запустите `mTC.app`.

Можно и не пользоваться архивом: соберите приложение из исходников в Xcode (см. «Разработка»). Собранное локально приложение карантина не получает.

## Где хранятся настройки

Все настройки лежат рядом с приложением:

```
mTC/
├── mTC.app
└── mTC-data/
    ├── settings.json   — настройки (можно править руками при выключенном mTC)
    ├── hotkeys.json    — горячие клавиши (удобнее менять в окне «Горячие клавиши…»)
    └── state.json      — что приложение запоминает само: окно, вкладки, пути панелей
```

- Чтобы удалить mTC без следов, удалите папку `mTC/`. Если включали автозагрузку, сначала выключите её.
- Чтобы перенести mTC вместе с настройками, перенесите всю папку `mTC/`.
- Если файл настроек повреждён, он переименовывается в `*.broken-<время>.json`, и mTC стартует с настройками по умолчанию.
- Одну папку `mTC-data` может использовать только один запущенный экземпляр. Не запускайте одну копию с общей шары у нескольких человек: пусть у каждого будет своя.

Для другой папки настроек укажите `--data-dir <путь>` или переменную окружения `MTC_DATA_DIR`.

Вне папки остаются только системные записи: объект входа (если включена автозагрузка) и выданные разрешения на доступ к папкам.

### settings.json

| Ключ | По умолчанию | Описание |
|---|---|---|
| `showInDock` | `true` | Показывать иконку в Dock. Если `false`, mTC живёт только в строке меню |
| `showHiddenFiles` | `false` | Показывать скрытые файлы |
| `showWindowAtLaunch` | `true` | Открывать окно при запуске. При автозапуске окно не открывается |
| `confirmMoveToTrash` | `true` | Спрашивать подтверждение перед перемещением в Корзину. Выключается галочкой «Больше не спрашивать» в самом диалоге |
| `editor` | `""` | Редактор для `F4`: пусто — системный редактор текста (обычно TextEdit); или имя программы (`"Visual Studio Code"`), путь к `.app`, bundle id (`"com.microsoft.VSCode"`). Если задан явно, `F4` открывает в нём и папки |
| `fileColors` | 6 групп | Цвет имён файлов по маскам: `[{"name": "Архивы", "masks": "*.zip;*.7z", "color": "purple"}, …]`. Цвет — `blue`, `green`, `orange`, `purple`, `teal`, `pink`, `brown`, `gray`, `indigo`, `mint`, `cyan` (подстраиваются под тему) или `#RRGGBB`. Срабатывает первое подходящее правило; `[]` — без раскраски. Папки не красятся |

## Строка меню и автозагрузка

- mTC держит иконку в строке меню. Если закрыть окно, приложение продолжит работать; вернуть окно можно через иконку, Dock или `⌃⌥T`.
- Автозагрузку включает пункт «Запускать при входе в систему» в меню иконки. После этого mTC появится в «Системные настройки → Основные → Объекты входа».
- Автозагрузка привязана к расположению `mTC.app`. Если вы перенесли папку, mTC при следующем запуске заметит это и обновит регистрацию.

## Клавиши

Все сочетания можно поменять: меню **mTC → Горячие клавиши…** (`⌘,`) или пункт в меню иконки в строке меню. Там список команд с поиском; клик по сочетанию удаляет его, «+ Добавить» — нажмите новое сочетание. Изменения применяются сразу и сохраняются в `mTC-data/hotkeys.json` (формат: `"copyToOtherPanel": ["f5", "shift+cmd+c"]`) — файл можно передать коллегам или положить в `dist-preset/`. Ниже — сочетания по умолчанию.

## Заметки

- **Создание архивов.** Диалог «Упаковать…»: имя, формат (ZIP, 7Z, TAR.GZ, TAR.XZ), пароль для ZIP с выбором шифрования: «Совместимое (ZipCrypto)» — по умолчанию, открывается где угодно, в том числе двойным щелчком в Finder, но защита слабая; «Надёжное (AES-256)» — Finder такой архив не откроет, нужен mTC, 7-Zip или Keka, галочка «в папку другой панели» (по умолчанию — в текущую). `.DS_Store` в архив не попадают. Архив пишется во временный файл и появляется только целиком.
- **Распаковка архивов.** zip (в том числе с паролем), 7z, rar, tar, tar.gz/bz2/xz, iso, cpio, pkg/xar, cab, одиночные .gz/.xz/.bz2 — через системную библиотеку, без сторонних программ. Архив распаковывается туда же, где лежит: один объект внутри — он и появляется (если имя занято — вопрос, как при копировании), несколько — появляется папка с именем архива. Элементы с `..` в пути пропускаются (защита от вредоносных архивов). При отмене ничего лишнего не остаётся. `Enter` или двойной клик по архиву не распаковывает его сразу, а спрашивает: «Распаковать сюда», «Открыть программой» или «Отмена» (`.pkg` и `.iso` открываются как обычно).
- **Открыть с помощью.** В контекстном меню и в меню «Файл»: все программы, которые умеют открыть файл (для нескольких — те, что открывают все), программа по умолчанию первой, в конце — «Другая программа…».
- **Перемещение.** Тот же диалог и те же вопросы при совпадении имён, что у копирования. На том же диске — мгновенно; на другой диск — копирование и удаление исходника, только если он скопирован полностью (при отмене или ошибке исходник остаётся).
- **Копирование.** Идёт в фоне, окно прогресса появляется, если копирование длится дольше полсекунды; с панелями можно работать дальше. Если файл уже есть: «Заменить», «Пропустить», «Оставить оба» (копия получит номер: «файл 2.txt») или остановить; галочка «Применить ко всем». Папки с одинаковыми именами сливаются. Замена безопасна: новый файл сначала копируется рядом и только потом подменяет старый. Скопированные файлы снимаются с выделения. На одном диске APFS копирование мгновенное (клонирование).
- **F-клавиши.** На клавиатурах Mac F-клавиши по умолчанию нажимаются вместе с `fn` (или включите «Использовать F1, F2 и т. д. как стандартные функциональные клавиши» в настройках клавиатуры). У каждой операции есть и обычное сочетание, а внизу окна — кнопки, как в Total Commander.
- **Вкладки.** У каждой панели свои вкладки; строка вкладок появляется, когда их больше одной. Каждая вкладка помнит папку, курсор, выделение и сортировку. Крестик или средняя кнопка мыши закрывают вкладку, правый клик — меню, двойной клик по пустому месту строки — новая вкладка. Вкладки сохраняются между запусками.
- **Диски.** Над каждой панелью список: диски (системный, внешние, сетевые), «Домашняя папка» и «Корень /», рядом свободное место. Выбор другого диска открывает папку, где эта панель была на нём последний раз; выбор текущего диска — его корень. Если диск, открытый в панели, отключить, панель перейдёт в домашнюю папку.
- **Автообновление.** Панели обновляются сами, когда в открытой папке появляются, исчезают или меняются файлы; курсор и выделение сохраняются. Изменения на сетевых дисках, сделанные с других компьютеров, macOS не сообщает — для них есть `⌘R`.
- **Разрешения.** При первом входе в «Документы», «Рабочий стол», «Загрузки» и на внешние диски macOS спросит разрешение. Приложение подписано ad-hoc, поэтому после обновления на новую версию macOS может спросить ещё раз.
- **Запуск из карантина.** Если снять карантин забыли, mTC сообщит об этом при старте и предложит скопировать нужную команду.

## Разработка

Нужен Xcode 26 или новее.

- Откройте `mTC.xcodeproj` и запустите (`⌘R`). В режиме отладки настройки хранятся в `mTC-data-dev/` в корне проекта. Путь задаёт переменная `MTC_DATA_DIR` в схеме mTC.
- `scripts/dist.sh` собирает Release и упаковывает `build/mTC-<версия>.zip` для раздачи.
- Если в корне проекта есть папка `dist-preset/`, её содержимое попадает в `mTC-data/` архива. Так можно раздавать команде общие настройки.
- Версия задаётся в `MARKETING_VERSION` в настройках проекта.

Структура исходников:

```
mTC/
├── App/          — точка входа, AppDelegate, главное меню
├── Core/         — папка данных, хранилище JSON, модели настроек
├── System/       — строка меню, глобальная клавиша, автозагрузка
├── FileSystem/   — чтение каталогов, сортировка, иконки
└── UI/           — окно и файловые панели
```
